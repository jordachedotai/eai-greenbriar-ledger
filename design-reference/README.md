# Portfolio Initiative Ledger: design reference

Canvas: https://claude.ai/code/artifact/d3952185-ed33-47ea-a29d-b17eb5fcab9e (drafted 2026-09-09)

Four artboards, built by `build.py` from shared fragments. Tokens match the scheduler POC (`../portco-scheduler-poc/design-reference/Tokens.dc.html`): Source Serif 4 titles, Source Sans 3 body, header #143f1f, brand #1f5a2d, status system one meaning per color (on track #15733f, slipping #8a5a08, needs a conversation #c8434f, not reported #8a978a, needs you #2b5f9e).

- `Main.dc.html`: Portfolio, August 2026. 3 fictional companies, 12 initiatives, 8 month cells each.
- `Company.dc.html`: Harlan Industrial Services, ERP migration selected. Stacked monthly quotes with page cites, drafted questions rail.
- `Patterns.dc.html`: cross-company parallels plus the learning log.
- `Spine.dc.html`: vision board, the initiative as the spine from IC memo to exit.

Fictional companies only: Harlan Industrial Services, Meridian Freight Partners, Corvus Aviation Services. Never a real portco.
The wordmark image is not copied here; the build takes it from the scheduler repo's `public/greenbriar-logo.png`.
